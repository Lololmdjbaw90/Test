# Editor fonts

Unmodified font binaries from https://github.com/google/fonts/tree/main/ofl,
downloaded September 29, 2026. Each family's copyright notice and SIL Open
Font License 1.1 are bundled alongside its font as `<family>-OFL.txt`.
These licenses allow bundling with software when the notices are retained.

The requested personal-use/demo archives are not included in the app.
The following alternatives provide a similar range of playful styles, rather
than claiming to be identical replacements:

| Requested | Bundled alternative |
| --- | --- |
| Mochibop | Bubblegum Sans |
| Shooting Star | Pacifico |
| Beachday | Lilita One |
| Child Hood | Balsamiq Sans |
| Qilka | Chela One |
| Mochi Boom | Modak |
| Milkyway | Caveat Brush |

Source folders: `bubblegumsans`, `pacifico`, `lilitaone`, `balsamiqsans`,
`chelaone`, `modak`, `caveatbrush`. No font files were modified or renamed.
